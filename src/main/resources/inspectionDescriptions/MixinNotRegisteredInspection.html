Reports Mixin classes that are not registered in any mixins.json configuration file.

Mixin classes must be registered in a *.mixins.json file to be loaded by the Mixin framework. This inspection checks if the class annotated with @Mixin is listed in any of the following arrays in any mixins.json file in the project:

  • mixins - common mixins
  • client - client-side mixins
  • server - server-side mixins

If a Mixin class is not registered, it will not be applied at runtime.
