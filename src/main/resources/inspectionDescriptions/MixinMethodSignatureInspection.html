Reports invalid Mixin handler method signatures.

This inspection checks that Mixin handler methods (methods annotated with @Inject, @Redirect, etc.) have the correct signature based on their annotation type and target method.

Standard Mixin Annotations

@Inject methods should:

  • Have parameters matching the target method parameters
  • Have a CallbackInfo parameter (for void targets) or CallbackInfoReturnable (for non-void targets)

@Redirect methods should:

  • Have a return type matching the redirected method
  • Have parameters matching the redirected method (plus instance if non-static)

@ModifyArg, @ModifyVariable, @ModifyConstant methods should:

  • Have at least one parameter (the value being modified)
  • Have a return type matching the parameter type

@ModifyArgs methods should:

  • Have an Args parameter
  • Return void

Mixin Extras Annotations

@WrapMethod methods should:

  • Have the same parameters as the target method (plus instance if non-static)
  • Have an Operation parameter as the last parameter
  • Have the same return type as the target method

@WrapOperation methods should:

  • Have an Operation parameter

@WrapWithCondition methods should:

  • Return boolean

@ModifyExpressionValue, @ModifyReturnValue, @ModifyReceiver methods should:

  • Have the original value as the first parameter
  • Have a return type matching the parameter type

Quick fixes are available to correct invalid method signatures.
